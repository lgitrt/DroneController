# Quick Reference: Running the Simulation

## One-Liner (from MATLAB command line)

```matlab
cd DroneSimulation/matlab
run_controller_comparison
```

## What You'll Get

1. **5 PNG figures** in `results/` showing:
   - Circle tracking (XY plane overlay)
   - Position tracking over time (X, Y, Z)
   - Attitude angles (roll, pitch, yaw)
   - Rotor commands (motor speeds)
   - RMSE comparison bar chart

2. **Console output** with performance metrics:
   ```
   Overall RMSE [m]: Aggressive = 0.0051, Conservative = 0.0266
   Control effort [rad²/s²]: Aggressive = 11503, Conservative = 6483
   ```

## Key Files

| File                           | Purpose                                    |
|--------------------------------|--------------------------------------------|
| `run_controller_comparison.m`  | Main entry point                          |
| `parameters.m`                 | Physical constants & design specs         |
| `designLQR.m`                  | LQR gain computation (tuning strategies)  |
| `simulateClosedLoop.m`         | Closed-loop simulation loop                |
| `circleTrajectory.m`           | Reference path generator                  |
| `plotComparison.m`             | Figure generation                         |
| `QuadrotorStateFcn.m`          | Nonlinear dynamics (autogenerated)        |
| `quadrotorLinearModel.m`       | Linearized A, B matrices                  |

## Default Trajectory

- Radius: 2 m
- Period: 30 s (ω = 2π/30 rad/s)
- Altitude: 2.5 m
- Ramp-up: 5 s (quintic smooth-start)
- Total time: 45 s

## Customization Examples

**Faster circle (10 m/s tangential speed):**
```matlab
traj.radius = 5;
traj.omega = 2*pi/20;  % 20 s period
```

**Aggressive controller only:**
```matlab
K = designLQR(p, 'Tuning', 'Aggressive');
out = simulateClosedLoop(p, traj, lqrControllerAgg, 0.01, 45, zeros(12,1));
```

**Compare with default (Balanced) tuning:**
```matlab
K_bal = designLQR(p, 'Tuning', 'Balanced');
controllerBal.type = 'LQR';
controllerBal.K = K_bal;
```

## Simulation Details

- **Integration method:** RK4, 10× sub-stepping per control cycle
- **LQR sample time:** 0.01 s (100 Hz)
- **Nonlinear model:** Full 12-state dynamics, no approximations
- **Reference:** Ideal smooth trajectory with feedforward attitude commands
- **Disturbances:** None (ideal sensors, no wind/noise)

## Troubleshooting

**Q: Cannot find `parameters.m`?**  
A: Make sure you run `addpath('matlab')` first, or `cd` into the `matlab` folder.

**Q: Plots are blank or errors about graphics?**  
A: Figures are saved to `results/` as PNG even if display fails. Check that folder.

**Q: How do I change controller weights?**  
A: Edit the Q and R matrices in `designLQR.m`, or add a new `'Tuning'` case.

**Q: Can I use this with hardware?**  
A: The LQR gain is just a 4×12 matrix. Export to C or Python (numpy), apply `u = u_hover - K @ (x - x_ref)` on your flight controller at 100+ Hz.

## Further Reading

- **Quaternion vs Euler angles:** This code uses Euler angles (roll/pitch/yaw) and small-angle linearization. For large-angle control, use quaternions + nonlinear MPC.
- **Model Predictive Control:** Template in `designNMPC.m` can be debugged for nonlinear trajectory optimization.
- **Gain scheduling:** Extend LQR to multiple hover points (e.g., forward flight) by designing K at different equilibria.
